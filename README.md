# Base

Versiones de **Base**, el escritorio personal para Windows.

Base se fija solo en `version.json` y, si hay una versión nueva, ofrece actualizarse con un clic.
Los datos de cada compu (tareas, notas, cuentas de Google) no están acá: quedan en cada compu.

## Si una compu no se puede actualizar sola

Bajá [`Actualizar Base.cmd`](https://raw.githubusercontent.com/Redux-7/base-escritorio/main/Actualizar%20Base.cmd) (clic derecho → Guardar como), y abrilo con doble clic.
Baja la última versión y reemplaza solo el programa; tus datos quedan como están.
